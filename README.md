# SC3KU Enhancements

Two free enhancement editions for an owned Windows copy of **SimCity 3000 Unlimited**.

| Edition | Included | Installation |
| --- | --- | --- |
| **Combined** | NanoFives plus the Enhancement Collection | One combined install; options in the game |
| **Standalone** | Enhancement Collection without NanoFives | Select modules in the installer |

Download the complete installer ZIP from this repository's **Releases** page.
GitHub's automatic **Source code (ZIP)** is for developers and is not a playable installer.
The separate source download is not a third game edition.

## Install

1. Extract the entire installer ZIP and close SimCity.
2. Run **Install.cmd** and allow the Windows permission prompt if requested.
3. Select GOG/Steam or paste the installed game folder; follow the displayed steps.
4. Start normally through the store or your usual game shortcut.

Use one edition per installation. Keep the local backups. **Remove.cmd** restores
original runtime files while retaining cities/preferences. Unknown modified files
are refused rather than forced over. Do not stack a separate Nano patch or standalone
modules over the combined package.

## Highlights

- Combined: 512–1024 maps, expanded transport networks, camera controls, graph/data
  improvements, autosave/undo, Move/Restore/Empty tools and placement/transit hints.
- Combined: in-game display mode and supported next-launch size presets, Alt+Enter,
  extra city zoom, pause/speed keys and background music mute.
- Both: enhanced roads/lighting, landscapes, parks, gardens, statues, civic extras,
  Plymouth Arcology, hydro dams, waterfront assets, weather and custom disasters.
- Both: native appearance replacement for 19 ordinary custom buildings. Specialized
  beaches, dams, docks, promenades, piers and walls keep their existing behavior.

Read the edition feature guides under `docs/`, including known limits. Weather can
be light on large maps. Arbitrary live window resizing and enlarged sharp UI scaling
are not enabled in this release. Replacement choices require compatible lot sizes.

## Source and licensing

`src/combined` and `src/standalone` contain the available code, SDK/source notices,
data recipes and build guidance. The verified adapter kits have their own instructions.
Some older art/plugins survive as finished assets; a complete rebuild of every legacy
asset is not supplied. Original project code/docs use the scoped project MIT license;
third-party licenses remain in effect. Game and game-derived asset rights are excluded.

This is an unofficial fan modification. The full game, saved cities, credentials,
crash dumps and local game backups are not supplied. No personal author byline or
contact details are required to install or use the mod.

For reproducible issue reports, use the bug-report form and include the edition,
store, map size and exact action. Remove private details from any logs you share.
